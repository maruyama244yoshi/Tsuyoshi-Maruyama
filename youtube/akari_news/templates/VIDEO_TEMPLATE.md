# 動画テンプレート

## 画面の約束事（16:9, 1920x1080）

| 領域 | 内容 |
|---|---|
| 上部 0–100px | ヘッダー：ロゴマーク＋「燈の不動産NEWS」＋ゴールドのコーナーラベル（シーン名）＋補足 |
| 中央 100–860px | 図表／キャラクターカット（キャラは右、キーワードは左） |
| 下部 860–1080px | 字幕帯（ネイビー半透明、白文字、話者ラベル：燈＝ゴールド／大家M＝ベージュ） |

- 数字は大きく。出典・注記は右下に小さく必ず表示（一次資料名・日付／試算注記）。
- 色は `AKARI_COLOR_PALETTE.json` のみ。赤は警告、緑はポジティブ数値のみ。
- 「大家の一手」はジングル＋専用カード（G09）から入る。

## 縦型（Shorts, 1080x1920）

上：キャラクターパネル／中：要点グラフィック／下：字幕（1行16文字前後）。45〜60秒。最後に本編への導線。

## visual ID の書き方（episode.json）

- `cut:akari_front` `cut:akari_desk` `cut:ooka_m` `cut:ooka_m_think` … キャラクターカット（シーンごとにキーワード自動）
- `gfx:<ID>` … `graphics.py` の関数で描画する図表
- `vgfx:<ID>` … 縦型図表

新しい図表は `graphics.py` に関数を追加し、`render_episode()` の辞書に登録する。
