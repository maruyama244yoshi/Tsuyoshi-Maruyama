## 標準化・自動化できる箇所

| 工程 | 現在 | 自動化案 |
|---|---|---|
| ニュース選定 | 手動 | NEWS YAGURA JSON → `score.py` → 70点以上を候補化 |
| 台本ドラフト | 指示書から手動構造化 | script_package → episode.json 変換を自動化（Claude） |
| 大家Mコメント | 指示書記載 | suggested を自動生成 → 承認UI（スプレッドシート or 簡易Web）で approve |
| 数値・禁止ワード検証 | 自動 | CI（GitHub Actions）で PR ごとに実行 |
| 図表 | 関数追加で対応 | 定番図表（金利推移・前年比・地域比較）をパラメータ化 |
| 音声・字幕・動画 | コマンド4本 | 1コマンド化（`make episode EP=episode_002`） |
| サムネ | 自動3案 | 文言3案をscript_packageから流し込み |
| 公開 | 手動 | 手動のまま（YouTube Data API は下書き・非公開アップロードまでに限定する案） |
