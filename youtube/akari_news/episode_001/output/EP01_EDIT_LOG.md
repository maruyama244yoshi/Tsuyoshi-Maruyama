# EP01 編集ログ（第2稿）

## 使用素材

- 話している動画：本編 AKARI_001〜016、M_001〜005／Shorts AKARI_017（SHORT_01）、AKARI_018・M_006（SHORT_02）
- 声だけの音声：本編 AKARI_VO_001〜015、M_VO_001〜002／Shorts AKARI_VO_016〜018
- AKARI_VO_015 は修正版（貸出態度「全般について」）を使用。画面に注記「※企業等への貸出を含む全般についての評価。不動産投資向け融資に限った評価ではありません」を表示
- 未使用素材：なし（44本すべて使用）

## 音声

- Voice・Speed・Pitch は一切変更していない（Jhenny／Satoshi、Speed 1.0）。無音カット・速度調整もしていない
- 話している動画は動画内の音声をそのまま使用（口パクと完全同期）。声だけの音声は図表の上にのみ配置し、話している動画の音声とは重ねていない
- 声だけの音声は中身がMP3だったため、編集用に48kHz/24bit WAVへ1回だけ変換（元ファイルは inbox に保持。MP3への再圧縮はしていない）
- 発話ごとの音量を揃えたうえで、完成ファイルを -16 LUFS（YouTube向け）に調整。燈と大家Mの元の音量差（約4dB）は解消
- BGM：自作の落ち着いたニュース系BGM。声のある間は自動で音量を下げる（サイドチェイン）。「大家の一手」の前だけ短いチャイム

## 映像

- 構成：HOOK → 何が起きたか → ここを勘違いしない → 見るべき数字①②③ → 大家Mコメント → 大家の一手 → 燈まとめ → CTA
- 人物 → 図表 → 人物の往復。最長の連続人物カットは M_003（14.9秒）
- 出演比率：燈 27.1％、大家M 11.7％、図表 61.2％（燈は目安30〜40％に未達。QA_REPORT参照）
- 名前表示：燈（あかり）／AI不動産ニュースキャスター、現役会社員大家M（実名なし）
- 図表：既存15点＋「大家Mコメント（物件選び×金融機関選び）」1点を追加（今回は未使用）。数字のカウントアップ、バーの伸長、段階表示などの控えめなアニメーション
- 字幕：通常表記（ひらがなの読み上げ原稿は使っていない）。重要語（1.25％・444万円・459万円・15万円・返済比率・DSCR・0.5％・1.0％・年間返済額）を金色で強調
- B-roll：実写素材が未支給のため不使用（図表で代替）

- Shorts の図表に古い仮素材（キャラクターボードの切り抜き）が出ていたため番組パネルに差し替え
