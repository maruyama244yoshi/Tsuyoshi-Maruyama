## 0. 決定事項（2026-09-25 指示書）

- 声：ElevenLabs を第一候補。燈3声・大家M2声を比較（35点満点、28点以上）
- 動画：HeyGen と Hedra を比較（同じ音声・同じ画像）。D-ID・Kling AI は後回し
- 自動化は急がない。第1〜10本程度は画面操作で品質を固定し、条件（§25）を満たしてから API 化
- テストの手順・採点表・規約確認・設定記録：`youtube/akari_news/avatar_tests/`、正式決定の記録：`brand/PRODUCTION_MASTERS.md`

## 1. 現状と制約

| 項目 | 状態 |
|---|---|
| 仕組み（ツール側） | ✅ 対応済み。話しているカット（mp4）を置けば、図表と往復する番組構成で自動で組み上がる |
| 出演比率 | ✅ 第2稿の構成で 燈30.6％／大家M13.8％／図表55.6％（仮音声での計測） |
| BGM | ✅ 声の下で自動的に下げる仕組みを実装（曲の選定待ち） |
| 自然に話す動画の生成 | ❌ **この制作環境ではできない** |

できない理由：
- 口パク動画・音声の外部サービス（HeyGen、Hedra、D-ID、ElevenLabs など）への接続が、この環境のネットワーク設定で遮断されている
- GPUがなく、手元でAIモデルを動かす方式（オープンソースの口パク生成）も現実的でない。モデルの配布元（Hugging Face）も遮断されている
- Google Cloud の音声合成（Text-to-Speech）には接続できる。APIキーがあれば、燈の女性の声はここで作れる

## 2. 方式の比較候補（テストで決める）

比較基準は指示書 §8 の順：① 顔の同一性 ② 口の自然さ ③ 瞬き・視線 ④ 日本語の同期 ⑤ 頭の揺れがない ⑥ 商用利用 ⑦ 制作時間 ⑧ 費用。

### 口パク動画（1枚の画像＋音声 → 話す動画）

| 候補 | 特徴（要テスト） | 確認すること |
|---|---|---|
| HeyGen | 写真1枚からアバターを作り、音声に合わせて話す動画を生成。APIあり | 日本語の口の形、頭の揺れの抑え方、商用利用の条件 |
| Hedra | 画像＋音声から表情付きで話す動画を生成。APIあり | 表情が大きすぎないか、同一人物性 |
| D-ID | 写真から話す動画。APIあり | 実写感、瞬き・視線 |
| Kling AI（口パク機能） | 動画生成＋口パク | 同一人物性の維持、尺の上限 |

- 実在の演者を撮影して作るタイプのアバターは、燈の顔を固定できないため対象外。
- 各サービスの機能名・料金・商用利用条件は改定が多い。**テスト時に公式情報で確認**する。

### 声（先に音声を作り、同じ音声で各ツールを比較する）

| 候補 | 備考 |
|---|---|
| ElevenLabs | 日本語の自然さ・抑揚の調整幅が大きい |
| にじボイス | 日本語特化の音声 |
| Google Cloud Text-to-Speech（日本語の高品質音声） | **この環境から接続可能**。APIキーがあれば自動化しやすい |

### ①② の実行方法（どちらかを選ぶ）

- **A. この環境から自動で作る（今後の量産向き）**
  - 必要：使うサービスの有料プラン（API利用可能なもの）と、この環境の設定変更（接続先ドメインの許可＋APIキーを環境変数に登録）
  - 利点：第2回以降、台本 → 音声 → 口パク動画 → 本編までを自動化できる
- **B. サービスの画面で手作業で作る（すぐ試せる）**
  - 必要：各サービスのアカウント。テストキットの画像・セリフ・設定どおりに作り、mp4をこちらへ渡す
  - 利点：設定変更なしで今日から比較できる
