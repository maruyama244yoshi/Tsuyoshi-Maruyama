# HANDOVER.md テンプレート

Session 終了時、Snapshot.md と併せて必ず生成する。

内容は以下の6項目 **のみ**。

以下をコピーして使用する。

```markdown
# HANDOVER

作成日: YYYY-MM-DD

## Mission

（引き継ぐ任務を1〜2行で）

## Version

- （対象 OS と Version。例: Commander v1.3）

## 成果物

- （完成物へのパス・名称を箇条書き）

## 残Task

- [ ] （未完了タスク）
- [ ] （未完了タスク）

## 次Action

1. （新 Session が最初に実行すること）

## Risk

- （引き継ぎ時点で判明しているリスク）
```

## Snapshot との違い

| | Snapshot.md | HANDOVER.md |
|---|---|---|
| 目的 | Session の状態記録 | 次 Session への引き継ぎ |
| 読者 | 新 Session（開始時に読込） | 次の作業者・新 Session |
| 内容 | 9項目（決定事項・注意事項を含む） | 6項目（実行に必要な最小限） |

## ルール

- 6項目以外を追加しない。
- 箇条書きのみ。長文禁止。
