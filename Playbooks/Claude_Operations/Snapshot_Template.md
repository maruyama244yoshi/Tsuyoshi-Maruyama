# Snapshot.md テンプレート

Session 終了時に必ず作成する。**長文禁止。1〜2ページ以内。**

以下をコピーして使用する。

```markdown
# Snapshot

作成日: YYYY-MM-DD

====================

## Mission

（この Session の目的を1〜2行で）

## 現在Version

- Commander: vX.X
- （関連する OS の Version のみ列挙）

## North Star

（最終ゴールを1行で）

## 成果物

- （作成・完成したものを箇条書き）

## 更新内容

- （この Session で更新したものを箇条書き）

## 未完了

- （やり残したことを箇条書き）

## 次Action

1. （次 Session で最初にやること）
2. （その次）

## 重要決定事項

- （この Session で決めたこと。理由は1行まで）

## 注意事項

- （次 Session が知るべきリスク・制約）

====================
```

## ルール

- 各項目は箇条書きのみ。段落・説明文を書かない。
- 経緯・議論の記録は書かない（それは Session の仕事、Snapshot の仕事ではない）。
- 1〜2ページを超えたら削る。
